# 🐞 Miraculous Interactive Transformation 🐱

> ✨ Experience the magic of Paris's greatest heroes! ✨

A fully interactive React + TypeScript website inspired by **Miraculous Tales of Ladybug and Cat Noir**! Step into the world of Kwamis, transformations, and superhero adventures with this immersive web experience! 🦸‍♀️🦸‍♂️

## 🎯 What Makes This Special?

🔥 **Virtual Miraculous Box** - Just like in the show! Click on Kwamis to discover their holders  
⭐ **Canon-Accurate Transformations** - Real spells, real sequences, real magic!  
💥 **Power-Up States** - Exclusive to Ladybug & Cat Noir (Lucky Charm & Cataclysm modes!)  
🎭 **Cinematic Animations** - Smooth, professional transitions using Framer Motion  
🎵 **Authentic Sound Effects** - Character-specific audio using Howler.js  
📱 **Fully Responsive** - Works perfectly on desktop, tablet, and mobile!  

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start the magic! ✨
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) and prepare to be amazed! 🎪

## 🎮 How to Play

1. **Choose Your Kwami** 🧚‍♀️  
   Click on any Kwami in the Miraculous Box to reveal their civilian holder!

2. **Transform!** ⚡  
   Click the transformation button and watch the magic happen!

3. **Power Up!** 💥  
   *Only for Ladybug & Cat Noir* - Activate their special powered-up forms!

4. **Detransform** 🌙  
   Return to civilian form when you're ready!

## 🎵 Adding Your Own Sounds

Place your audio files in `src/assets/sounds/`:
```
tikki-transform.mp3      # Tikki's transformation sound
tikki-detransform.mp3    # Tikki's detransformation sound
plagg-transform.mp3      # Plagg's transformation sound
# ... and more!
```

## 🖼️ Adding Character Images

Place character images in `src/assets/images/`:
```
kwamis/          # Kwami portraits
civilians/       # Civilian character images  
heroes/          # Superhero forms
```
